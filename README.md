# Лабораторна робота 5, варіант 8

Рядки в C. Дві окремі консольні програми.

- `task1.c` — з прізвища вилучає букви **а, А, о, О** (і латинські **a, A, o, O**).
- `task2.c` — сортує символи `S1` за зростанням, символи `S2` за спаданням. Пробіли теж сортуються.

На Windows програма сама перемикає консоль на UTF-8, тож українські літери читаються цілими символами.

## Компіляція

У каталозі `D:\Lab05`:

```text
gcc -std=c11 -Wall -Wextra -o task1.exe task1.c
gcc -std=c11 -Wall -Wextra -o task2.exe task2.c
```

## Запуск

```text
task1.exe
task2.exe
```

Приклад для завдання 1:

```text
Коваленко Тарас Григорович
```

Результат: прізвище `Квленк`.

Приклад для завдання 2:

```text
b a c
БаА
```

`S1` стає `  abc` (спочатку пробіли), `S2` — `аБА`.
